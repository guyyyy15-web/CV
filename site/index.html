Vinomate

AI sommelier kiosk Client project

I took an LLM-powered product from PRD to a clickable prototype, through 10 client iterations: an in-store tablet that recommends wine by taste, dish, occasion and budget, and remembers each customer.

  • 3 interfaces
  • 5 user roles

Read the full case study
Problem
The client wanted an in-store tablet that recommends by taste profile, dish, occasion and budget, and remembers what each customer chose so the next recommendation is sharper.
My role
Product manager on a client project: requirements, prototype and design handoff.
What I did
  • Wrote the PRD: testable, ID-tracked requirements for 3 interfaces (customer kiosk, store back office, super admin), 5 user roles, and a server-side LLM for the chat sommelier and catalog enrichment.
  • Built the interactive hi-fi prototype with Claude Code and took it through 10 client iterations: SMS/QR sign-in, taste-profile scales, a returning-customer feedback loop, event planning, offline guest mode, Hebrew RTL.
  • Wrote a 12-part Figma Make prompt library for design handoff, and worked on the investor deck.
Result
The client reacted to a working product instead of a document, across 10 iterations, and developers got a PRD they can build from.

HeChatzer החצר

Lists and chores for friends and family Own product

A live app I took from PRD to production on my own: who brings what to an event, and who does which chore at home, end-to-end encrypted. It shows I can spec, ship, test and run a product, not only describe one.

  • 105 automated tests
  • ₪0 a month up to ~1,000 daily users
Read the full case study
Problem
Friends and families plan events and split chores in group chats, where it is hard to see who brings what. HeChatzer gives the group one shared list, encrypted so the server only ever stores locked data.
My role
Everything: PRD, brand, every screen and the code, built with Claude Code from my own specs.
What I did
  • Offline-first PWA with AES-GCM encryption, ECDSA-signed events, and Face ID sign-in through passkeys.
  • Runs on Cloudflare Pages, D1 and R2, chosen to keep running costs at zero.
Result
105 automated tests (51 unit, 24 server, 30 browser on 3 phones) gate every merge in GitHub Actions. Designed to run at ₪0 a month up to ~1,000 daily users.

Try it live: hechatzer.pages.dev
