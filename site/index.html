Vinomate

AI sommelier kiosk Client project

I wrote the PRD and built the clickable hi-fi prototype for an in-store tablet that recommends wine by taste, dish, occasion and budget.

  • 3 interfaces
  • 5 user roles
  • 10 client iterations
Read the full case study
Problem
A wine store wanted an in-store tablet that recommends wine by taste profile, dish, occasion and budget, and remembers what each customer chose so the next recommendation is sharper.
My role
Product manager: requirements, prototype and design handoff.
What I did
  • Wrote the PRD: testable, ID-tracked requirements for 3 interfaces (customer kiosk, store back office, super admin), 5 user roles, and a server-side LLM for the chat sommelier and catalogue enrichment.
  • Built the interactive hi-fi prototype with Claude Code and took it through 10 client iterations: SMS/QR sign-in, taste-profile scales, a returning-customer feedback loop, event planning, offline guest mode, Hebrew RTL.
  • Wrote a 12-part Figma Make prompt library for design handoff, and worked on the investor deck.
Result
A clickable prototype the client reacted to across 10 iterations, backed by a PRD developers can build from.

Problem
A consumer app that reads a photo of the tongue and returns nutrition, sleep and lifestyle guidance, with family profiles and a subscription. The design had to be ready for development.
My role
Product manager: design audit, requirements, flows and wireframes.
What I did
  • Audited the design across 60+ screens and 17 flow areas.
  • Wrote the PRD and mapped the end-to-end flow.
  • Wireframed the screens, including a 22-screen family-profiles flow.
  • Ran competitor research with the client.
Result
20 issues logged before development: pricing conflicts, consent and sign-in gaps, unhandled acute-symptom answers.

Lists and chores for friends and family Own product

I designed and built an end-to-end-encrypted app for who-brings-what and shared chores. PRD, brand, every screen and the code, with Claude Code.

  • 105 automated tests
  • ₪0 a month up to ~1,000 daily users
Read the full case study
Problem
Lists, chores and who-brings-what for friends and family, with the data end-to-end encrypted so the server only ever stores locked data.
My role
Everything: PRD, brand, every screen and the code, built with Claude Code.
What I did
  • Offline-first PWA with AES-GCM encryption, ECDSA-signed events, and Face ID sign-in through passkeys.
  • Runs on Cloudflare Pages, D1 and R2.
Result
105 automated tests (51 unit, 24 server, 30 browser on 3 phones) gate every merge in GitHub Actions. Designed to run at ₪0 a month up to ~1,000 daily users.
